# Carrera 3D — MVP (ubicación fija)

- **Raíz del juego:** `outputs/code/X/` (relativo a esta carpeta de misión).
- **Stack:** Three.js vía CDN (sin bundler obligatorio), un solo HTML o HTML + JS.
- **Objetivo jugable:** coche que avanza en una pista simple, controles teclado, cronómetro de vuelta o tiempo hasta meta.
- **No** hace falta modelo 3D complejo: meshes básicos (cajas/planos) están bien.

Las rondas las define `paper-racing-loop` (6 pasos incremental).
