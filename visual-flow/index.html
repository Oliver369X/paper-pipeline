Meta-agente: Cursor sin escribir en el chat

paper-meta-watch vigila outputs/cursor_turn.md y, al guardar, lanza el mismo revisor que paper-meta-loop (Perplexity → next_instruction.md). Cursor sigue ese archivo (.cursorrules). Sin API de chat: archivos + reglas.

Modo supervisión — estados (hero)

IDLE · esperando RUNNING · Cursor trabaja WATCH · vigilancia de archivo REVIEW · Perplexity lee cursor_turn SAFE_STOP · límite o STOP DONE · objetivo cumplido

La simulación de abajo ilumina el ciclo. Parada segura: META_MAX_ROUNDS, primera línea STOP del revisor, error de red, token inválido, o Ctrl+C para el watcher.

Cuándo se detiene (sin infinito)
  • Tope de rondas: META_MAX_ROUNDS (por defecto 12).
  • Revisor STOP en next_instruction.md (riesgo o tarea lista).
  • Watcher: META_WATCH_POLL (s), META_WATCH_DEBOUNCE (s tras último guardado). Opcional META_WATCH_EXIT_ON_STOP=1 para cerrar al ver STOP.
  • cursor_turn.md vacío → no se llama a Perplexity.

Secuencia meta-agente

Detalle

Pulsa Simular ciclo meta (5 pasos) o un bloque. Flujo completo: archivo → watcher → Perplexity → instrucción → Cursor → otra vez el archivo.

Automático: con paper-meta-watch no hace falta ejecutar paper-meta-loop a mano cada vez: el watcher dispara el revisor al estabilizar cursor_turn.md. Sin API de chat en Cursor; el humano puede reducirse a “dejar corriendo el watcher” y revisar next_instruction.md.
