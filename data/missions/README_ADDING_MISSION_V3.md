# Añadir una segunda misión (Plan v3)

## Pasos

1. Copiar la estructura de una misión existente o crear `data/missions/<nuevo_id>/mission.md`.
2. Ejecutar el pipeline según [GUIA_FLUJO_COMPLETO.md](../../docs/GUIA_FLUJO_COMPLETO.md) o [GUIA_PRUEBAS_Y_DEBUG.md](../../docs/GUIA_PRUEBAS_Y_DEBUG.md).
3. Verificar artefactos listados en [docs/templates/mission_v3_checklist.md](../../docs/templates/mission_v3_checklist.md).
4. Actualizar [docs/preprint/COMPARATIVE_TABLES.md](../../docs/preprint/COMPARATIVE_TABLES.md) **Tabla 2** con los números reales.
5. No commitear `.env`, tokens ni rutas absolutas personales.
