**K-FAC-based curvature editing offers a promising, data-efficient way to reduce memorization in small language models (SLMs) by targeting low-curvature directions in the loss landscape, extending ideas from arXiv:2510.24256 to resource-constrained settings.**[1](https://www.goodfire.ai/research/understanding-memorization-via-loss-curvature)[2](https://arxiv.org/pdf/2510.24256.pdf)

This methodology adapts the paper's K-FAC decomposition to SLMs like Phi-3-mini (3.8B parameters), focusing on feasibility for your AI safety research at YAIS Lab.[3](https://huggingface.co/blog/jjokah/small-language-model)[4](https://encord.com/blog/microsoft-phi-3-small-language-model/)

## Problem Formulation

Memorization in SLMs occurs when models regurgitate training sequences verbatim, quantified by prefix-suffix exact match under greedy decoding: for prompt $$P$$ and target $$S$$, compute Levenshtein distance $$d(\hat{S}, S)$$ where $$\hat{S}$$ is generated output.[2](https://arxiv.org/pdf/2510.24256.pdf)[5](https://mansisak.com/memorization/)

High per-example loss curvature links to brittle memorization, but aggregate dataset curvature reveals low-curvature directions (flatter basins) correspond to rarely used, memorization-heavy weights.[2](https://arxiv.org/pdf/2510.24256.pdf)

Objective: Decompose MLP weights via K-FAC-approximated Fisher Information Matrix (FIM) $$\mathbf{F} \approx \mathbf{G} \otimes \mathbf{A}$$, where $$\mathbf{G} = \mathbb{E}[\mathbf{g}\mathbf{g}^\top]$$ (gradients) and $$\mathbf{A} = \mathbb{E}[\mathbf{a}\mathbf{a}^\top]$$ (activations), then prune low-curvature components to suppress recitation while preserving perplexity and reasoning.[6](https://github.com/n-gao/pytorch-kfac)[2](https://arxiv.org/pdf/2510.24256.pdf)

## Baselines

Compare against three classes from memorization mitigation literature, scaled to SLMs:[5](https://mansisak.com/memorization/)[7](https://arxiv.org/html/2410.02159)

| Method          | Description                          | Pros/Cons for SLMs                  |
|-----------------|--------------------------------------|-------------------------------------|
| Regularizers   | Add loss curvature penalties (e.g., SAM) during fine-tuning. [5](https://mansisak.com/memorization/) | Slow, ineffective on compute-limited SLMs. |
| Fine-tuning    | SFT/RLHF on retain set post-forget. [5](https://mansisak.com/memorization/) | Effective but expensive for SLMs. |
| Unlearning (BSN) | Train binary mask to maximize forget loss vs. retain. [2](https://arxiv.org/pdf/2510.24256.pdf) | Strong targeted suppression; requires labeled forget set unlike K-FAC. [2](https://arxiv.org/pdf/2510.24256.pdf) |

Use SVD truncation (prune low singular values) as data-free ablation.[2](https://arxiv.org/pdf/2510.24256.pdf)

## Proposed Method Outline

1. **Collect Statistics**: Stream ~1-5M tokens from SLM pretraining mix (e.g., FineMath + Dolma subset) through target SLM (Phi-3-mini). Buffer pre-MLP activations $$\mathbf{a}$$ (forward) and gradients $$\mathbf{g}$$ (backward under NLL). Compute $$\mathbf{A}, \mathbf{G}$$ per MLP layer.[3](https://huggingface.co/blog/jjokah/small-language-model)[2](https://arxiv.org/pdf/2510.24256.pdf)

2. **K-FAC Decomposition**: Eigendecompose $$\mathbf{G} = U_G \Lambda_G U_G^\top$$, $$\mathbf{A} = U_A \Lambda_A U_A^\top$$. For weight $$W \in \mathbb{R}^{p \times q}$$, project $$C = U_G^\top W U_A$$, sort pairs $$(i,j)$$ by curvature mass $$\Pi_{ij} = \lambda_i^G \mu_j^A$$. Retain top-$$\rho=60\%$$ mass pairs via mask $$M$$, reconstruct $$W' = U_G (C \odot M) U_A^\top$$.[6](https://github.com/n-gao/pytorch-kfac)[2](https://arxiv.org/pdf/2510.24256.pdf)

3. **Edit & Tune**: Apply to late MLP layers (e.g., 80% from end, as in OLMo edits). Sweep $$\rho$$, layers (0.1% compute via small labeled forget set). No retraining needed, unlike BSN.[2](https://arxiv.org/pdf/2510.24256.pdf)

4. **Evaluation**: Test on held-out memorized sequences (e.g., Dolma val, quotes), compute strict/loose accuracy, avg. Levenshtein. Track perplexity, MMLU-Pro Math, logic (e.g., Boar Etruscan).[2](https://arxiv.org/pdf/2510.24256.pdf)

Implement via PyTorch KFAC repo; fits Colab for SLMs.[6](https://github.com/n-gao/pytorch-kfac)

## Minimal Viable Result

Success if K-FAC edit on Phi-3-mini reduces strict recitation accuracy by >80% on unseen memorized set (e.g., historical quotes: <20% from 99%), outperforms BSN/SVD on OOD memorization while $$\Delta$$PPL <2 and logic retention >90%.[4](https://encord.com/blog/microsoft-phi-3-small-language-model/)[2](https://arxiv.org/pdf/2510.24256.pdf)

Demonstrate spectrum: memorization/math drop most, reasoning robust. This replicates/extends arXiv:2510.24256 to SLMs, enabling arXiv submission with ablation on 1-4B models.[3](https://huggingface.co/blog/jjokah/small-language-model)[2](https://arxiv.org/pdf/2510.24256.pdf)

## Experiment Setup
Train or fine-tune SLMs like SmolLM2-1.7B or Phi-3.5-Mini-3.8B on a memorization-prone dataset (e.g., subset of Dolma or Pile with duplicates) to induce overfitting. Collect K-FAC statistics (activation/gradient covariances A and G) on ~20M tokens from training data via forward/backward passes on target MLP layers (e.g., final 2-3 layers' gate/up projections). Edit weights by eigendecomposing to curvature basis, truncating low-curvature components (e.g., retain top 60% energy), then reconstruct.[4](https://arxiv.org/html/2510.24256v2)[5](https://huggingface.co/datasets/omrifahn/kfac-memorization-code)[6](https://news.ycombinator.com/item?id=45845835)[7](https://huggingface.co/blog/jjokah/small-language-model)[1](https://www.goodfire.ai/research/understanding-memorization-via-loss-curvature)

## Suggested Baselines
- **No intervention**: Untuned SLM as baseline for memorization levels.[4](https://arxiv.org/html/2510.24256v2)
- **SVD pruning**: Singular value decomposition on weights, retaining top components by magnitude.[4](https://arxiv.org/html/2510.24256v2)
- **Balanced Subnet (BSN)**: Supervised unlearning baseline that balances forget/retain sets.[4](https://arxiv.org/html/2510.24256v2)
- **Standard regularization**: Weight decay or dropout during fine-tuning.[8](https://arxiv.org/abs/1602.01407)

## Key Metrics
Primary: Memorization suppression via strict/loose extractability (% verbatim recitation on held-out memorized sequences, e.g., Dolma validation or custom duplicates) and nDCG@10 for ranked retrieval. Secondary: Perplexity on retain set (Pile-10k subset), downstream tasks (e.g., fact retrieval, arithmetic via lighteval), and curvature spectrum shift (e.g., % low-curvature mass removed). Compute extractability with multiple prompts (n=3/5/10) using probabilistic sampling for reliability.[9](https://github.com/ro-ko/Awesome-SLM)[10](https://www.alphaxiv.org/overview/2410.19482v3)[4](https://arxiv.org/html/2510.24256v2)

## Ablations
- Vary energy threshold (40%, 60%, 80% retained curvature mass) to balance forget/utility trade-off.[5](https://huggingface.co/datasets/omrifahn/kfac-memorization-code)
- Target layers (last 1 vs. 2-3 MLPs) and projections (gate_proj only vs. up_proj).[1](https://www.goodfire.ai/research/understanding-memorization-via-loss-curvature)
- Importance formula: Original (λ_i * μ_j) vs. modified (λ_i * μ_j * |C_ij|^2).[1](https://www.goodfire.ai/research/understanding-memorization-via-loss-curvature)
- Dataset duplication factor (1x, 10x, 100x) to scale memorization induction.[11](https://floriantramer.com/publications/scaling22/)

## File: gaps.md

<!-- section=gaps generated=2026-03-27T18:07:50.007160+00:00 model=best -->

- **Application to SLMs (<1B parameters):** arXiv:2510.24256 focuses on 1B-7B OLMo models; underexplored in resource-constrained SLMs where compute for K-FAC covariances may exceed training budgets, limiting feasibility for edge deployment.[1](https://arxiv.org/html/2510.24256v2)
- **Numerical stability for small eigenvalues:** Estimating low-curvature directions in SLMs risks instability due to noisy gradients in limited data regimes, unaddressed in the paper's larger-model sweeps.[2](https://www.themoonlight.io/fr/review/from-memorization-to-reasoning-in-the-spectrum-of-loss-curvature)
- **Post-editing fine-tuning dynamics:** Paper notes potential need for further training after edits to regain expressivity, but gaps in SLM-specific strategies to prevent memorization resurgence during adaptation.
- **Beyond MLP edits to attention layers:** Method targets MLPs; underexplored extension to attention mechanisms, critical for memorization in SLMs with sparser activations.
- **Low-resource data settings:** Bulk data assumption for covariance collection doesn't hold for domain-specific SLMs (e.g., medical, code); no analysis of curvature signals in small/fine-tuned corpora.[3](https://www.nature.com/articles/s41746-025-01653-8)
- **Interaction with quantization/distillation:** No evaluation of K-FAC robustness under 4/8-bit quantization or distillation common in SLMs, where curvature approximations may degrade.[4](https://www.emergentmind.com/topics/kronecker-factored-approximate-curvature-k-fac-cfb12415-7bdc-42ec-b0f2-bb04c447624a)
- **Task-specific brittleness in SLMs:** Arithmetic/fact recall drops observed in LMs; open whether SLMs show similar spectrum or if reasoning is uniformly robust due to scale limits.
- **Theoretical guarantees for aggregate curvature:** Empirical inversion (low aggregate curvature = memorization) lacks proofs for SLMs, where double descent alters loss landscapes.


## File: sota.md

<!-- section=sota generated=2026-03-27T18:08:10.590363+00:00 model=best -->

The state-of the art for K-FAC (Kronecker-Factored Approximate Curvature) loss curvature to mitigate memorization involves decomposing MLP weight matrices using activation/gradient covariances to identify low-curvature directions linked to memorized data recitation, then editing (pruning) those directions. This approach, novel for bulk memorization analysis, outperforms supervised unlearning baselines like Balanced Subnet (BSN) on untargeted suppression while preserving perplexity, and applies to small language models (SLMs) like OLMo-2 1B alongside 7B.[1](https://arxiv.org/html/2510.24256v2)[2](https://arxiv.org/abs/2510.24256)

## Key Method
K-FAC approximates the Hessian/Fisher via Kronecker products of activation (A) and gradient (G) covariances, yielding eigenvectors ordered by curvature mass (λ_i * μ_j). Low-curvature (bottom spectrum) components activate more on memorized inputs; editing retains top ~60% curvature mass in late MLP layers (e.g., 23-25), suppressing recitation without retraining data.[3](https://www.goodfire.ai/research/understanding-memorization-via-loss-curvature)[1](https://arxiv.org/html/2510.24256v2)

## Benchmark Datasets
- Dolma validation: Prefixed training sequences (64-token prefix, 48-token suffix) for targeted memorization.[1](https://arxiv.org/html/2510.24256v2)
- Historical Quotes: Out-of-distribution memorized quotes (8-token suffix) testing untargeted suppression.[1](https://arxiv.org/html/2510.24256v2)
- Pile10k: Clean text for perplexity.[1](https://arxiv.org/html/2510.24256v2)

## Standard Metrics
- Strict Accuracy (%): Exact match of generated suffix (lower better for suppression).[1](https://arxiv.org/html/2510.24256v2)
- Loose Accuracy (%): ≥75% token overlap (lower better).[1](https://arxiv.org/html/2510.24256v2)
- Avg Normalized Levenshtein Distance (higher better, ~0-1).[1](https://arxiv.org/html/2510.24256v2)
- Perplexity (PPL, lower better for utility preservation).[1](https://arxiv.org/html/2510.24256v2)

## Architectures/Paradigms
Transformer LMs (OLMo-2 1B/7B: MLP-focused edits in late layers) and ViTs (86M params, ImageNet, MLP layers 0/11 at 75% retention). Paradigm: Data-free curvature pruning post-training, scalable via ~20M token stats; low-curvature links to brittle tasks like math/facts, high-curvature to reasoning. No SLM-specific extensions beyond OLMo-1B as of March 2026.[2](https://arxiv.org/abs/2510.24256)[5](https://mansisak.com/memorization/)[3](https://www.goodfire.ai/research/understanding-memorization-via-loss-curvature)[1](https://arxiv.org/html/2510.24256v2)
